PASOS PARA USAR:
────────────────────────────────────────────────────────────────────────────

1. Abrir Simu.slnx en Visual Studio 2022

2. Configurar appsettings.json (conexión SQL)

3. Registrar servicios en Program.cs de API

4. Ejecutar migraciones EF Core:
   dotnet ef migrations add InitialCreate
   dotnet ef database update

5. Ejecutar Simu.API (F5)

6. Ver Swagger: https://localhost:5001/swagger

7. Desarrollar componentes Blazor según necesidad

## 🎯 Archivos Clave por Rol

### **Si eres DBA (Base de Datos)**
Enfócate en:
- `Simu.Data/Context/SimuDbContext.cs` → Configuración de tablas y relaciones
- `MIGRACION_SIMU.md` → Sección de migración de datos

### **Si eres Backend Developer**
Enfócate en:
- `Simu.API/Controllers/` → Crear más endpoints
- `Simu.Business/Services/` → Lógica de negocio
- `Simu.Data/Repositories/` → Consultas a BD

### **Si eres Frontend Developer**
Enfócate en:
- `Simu.Blazor.Web/Components/Pages/` → Crear páginas
- `Simu.Blazor.Web/wwwroot/` → Estilos y assets
- `QUICK_START.md` → Setup rápido

### **Si eres DevOps/SysAdmin**
Enfócate en:
- `appsettings.json` → Configuración de ambiente
- `launchSettings.json` → Puertos y URLs
- MIGRACION_SIMU.md → Sección de deployment

### **Si eres Architect/Lead**
Enfócate en:
- `MIGRACION_SIMU.md` → Arquitectura general
